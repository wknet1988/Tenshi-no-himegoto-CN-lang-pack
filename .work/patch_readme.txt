天使のひめごと — 简体中文汉化补丁（序章 + UI）
================================================

【使用方法】
把补丁里的两个文件放进游戏目录（与 lcsebody.exe 同级），覆盖原文件：

    lcsebody        ← 数据包（含全部脚本、图片、音效索引）
    lcsebody.lst    ← 文件索引

建议先备份原版的这两个文件。

【本次汉化范围】
· 序章全部：OP001 / OP002 / OP003 / OP004 / OP005A / OP005B / OP006
  以及 3 个选择分支的选项文本
· UI 文本：读取存档确认框
· 共 982 条文本

【未汉化的部分（有意保留）】
· OP005A 第 125 条之后共 52 条 —— 该段涉及未成年角色的性描写内容，未做翻译，
  游戏中仍显示日文原文。剧情在此处仍可正常推进。
· 标题画面菜单文字（はじめから / つぎから / CG viewing 等）是位图图片资源，
  未重绘，仍为日文。

【技术说明】
原引擎按系统 ANSI 代码页解码文本（GBK/936），中文系统下直接以 GBK 写入即可
正确显示，无需修改 exe。文本字体已由「ＭＳ ゴシック」替换为「宋体」。

【兼容性】
游戏使用旧版 DirectInput，在 Windows 10/11 上可能需要：
· 以管理员身份运行
· 或将兼容性设置为 Windows 7/XP

若启动时提示 DirectInput 错误或随后崩溃，属原版在现代 Windows 上的兼容问题，
与汉化无关（原版同样如此）。
