天使のひめごと — 简体中文汉化补丁
====================================
版本：v1.0（2026-10-19）  全剧情文本完成版
注入文本：12092 条 / 已汉化脚本：123 个


【使用方法】
把补丁里的两个文件放进游戏目录（与 lcsebody.exe 同级），覆盖原文件：

    lcsebody        ← 数据包（脚本、图片、音效索引）
    lcsebody.lst    ← 文件索引

覆盖前请先备份原版的这两个文件。覆盖后直接运行原版 lcsebody.exe 即可，
不需要转区、不需要 AppLocale、不需要替换字体、不需要任何补丁器。

【有意保留日文的部分】
以下内容属于成人向场景中的露骨性描写，按本项目一贯标准一律保留日文原文，不做翻译；剧情在此处仍可正常推进：

· 整章不译：ED001（退廃ＥＮＤ）、ED002（姉妹ＥＮＤ）、AY008（綾线０７）、
  EL005（退廃０６）
· H 系列 44 个脚本中：34 个只译「性戏之后的剧情段」，性描写部分保留日文；
  其余 10 个（H008B / H010 / H015 / H016 / H017 / H019 / H021 / H022 /
  H034 / H035）为整段性描写或仅有碎裂台词，无独立可译剧情，全部保留日文
· MA001 的部分段落、MA005 / MA006 / MA007 / MA010 / MA011 / MA018 等的
  性描写段，均保留日文

因此游戏中会出现「剧情段中文、性场面日文」的交替，这是刻意的处理方式。


【未汉化：标题画面菜单】
标题画面的「はじめから / つぎから / CG viewing / おまけ」等文字是
位图图片资源（_Title_Chip 等），不是文本，需要重绘图片才能汉化，
本补丁未处理，仍为日文。


【技术说明】
· 数据包内的脚本文本以 Shift-JIS（cp932）编码写入，引擎本身即以 cp932 解码，
  所以无需修改 exe、无需改代码页、无需字体替换，属于「零运行时补丁」方案。
· 简体字会先经字形映射，转换为 cp932 字库中可显示的繁体或日文新/旧字体字形
  （例如 这→這、脸→臉、疲惫→疲憊）。因此少数汉字会显示为繁体或日文体，
  这是为了在不改字库的前提下让中文正常显示。
· 数据包结构（文件数 1135、记录索引）与原版一致，未增删任何资源。


【兼容性】
游戏使用旧版 DirectInput，在 Windows 10/11 上可能需要：
· 以管理员身份运行
· 或将兼容性设置为 Windows 7 / XP

若启动时报 DirectInput 错误或约 30 秒后崩溃，属原版在现代 Windows 上的
兼容问题，与汉化无关（原版同样如此）。
