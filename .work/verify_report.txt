天使のひめごと 汉化版 — 版本测试与修复报告
=============================================
测试时间：2026-10-16
测试对象：cn/ 游戏目录 + .work/zh 译文源 + 打包流程

一、初始状态：版本已损坏（不可用）
-----------------------------------
1. cn/lcsebody.lst（数据包索引，86264B）内容全为 0x00
   → 游戏靠它把脚本名映射到数据包内偏移，全零 = 无法加载任何文件。
2. .work/zh/*.json（20 个译文）文件大小保留，但内容被写满 0x00
   → 打包注入的是空集。
3. cn/lcsebody（239MB）主体是日文
   → 字节检索：です 933 次、ます 490 次；中文 秘事 0 次、中文 0 次。
结论：当前版本无法显示中文，且索引损坏会导致加载失败。

二、可恢复资源（已找到）
-----------------------
- tenshi/lcsebody.lst 原版索引完好（1135 条，unk 1:156 / 3:979）。
- .work/zh_backup/ 有 9 个完好译文 JSON（序章 OP001–OP006、OP005A/B、INIT、_LOADATTITLE），
  解析正常，例：INIT#8 = "要以全屏模式启动吗？"。
- .work/extract/ 日文底稿完好（1135 文件）。
- 真实丢失：AY003/007/009/010/011/013/014/016/017、CM001/CM002 共 11 个译文 JSON
  （主目录清零且 backup 无），需重译或重建。

三、修复过程（用户授权：恢复序章并重建）
---------------------------------------
1. 重新解包 tenshi 原版 -> .work/extract（干净日文底稿，1135 文件）
2. 把 11 个损坏译文移入 .work/zh/_corrupted/ 留证；从 zh_backup 恢复 9 个译文。
3. 【关键】运行 tools/to_jp.py --apply：把简化字映射成 cp932 可编码的日文/繁体字形。
   （遗漏此步会导致 ~49% 字符串变成问号）
4. 运行 tools/build_zh.py：注入译文 + 重新打包 -> .work/build/
5. 复制 .work/build/lcsebody 与 .lst 到 cn/。

四、修复后验证结果
-----------------
- cn/lcsebody.lst：1135 条记录，unk 分布 1:156 / 3:979（索引已修复）
- 注入译文：987 条（序章+INIT 全部）
- 中文回检：译文片段命中数据包（utf8->cp932->XOR 落在 cn/lcsebody）
- 含问号 ? ：0  （关键问题已消除）
- 含中点 ・ ：349 个字符串（源自 72 个 to_jp 仍无法映射的汉字，约占 5.2%，后续可打磨）
- OP001 抽样解码（已正确显示中文，繁/日字形）：
    "閉上眼睛，浮現在眼前的永遠都是同一張顔。"
    "小小的、令人懐念的与兩人共度的日子。"

五、当前方案说明
----------------
采用「中文 -> 映射为日文/繁体汉字 -> cp932 直出」方案，引擎原样用 932 解码即可显示，
因此 launch_cn.py 运行时零编码补丁，仅把窗口标题改为「天使秘事」。
（注：旧项目记忆里记载的 GBK+内存补丁方案已废弃，本次已据实重写。）
