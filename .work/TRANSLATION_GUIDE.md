# 汉化翻译规范 — 天使のひめごと 序章

## 输出格式（严格遵守）
输出 JSON 对象，key 为 `"<文件名>#<字符串下标>"`，value 为**完整替换后的字符串**（含控制符）。

**最关键**：value 必须保留原文的所有控制字符结构，只把日文替换为中文。
- 旁白/叙述类：原文形如 `\x01　正文\x02\x03` → value 形如 `\x01　中文正文\x02\x03`
- 对话类：原文形如 `绫\x01「台词」\x02\x03` → value 形如 `绫\x01「中文台词」\x02\x03`
- 标题类：`プロローグ０１　` → `序章１　`（保留结尾全角空格）
- 选项类：`抱き寄せる` → `抱上去`（纯文本，无控制符）
- UI 类：`No:\x04\x04\x00\x00\x00をロードします。よろしいですか？` → `No:\x04\x04\x00\x00\x00 要读取存档，是否继续？`（\x04 是数字占位符，必须原样保留）

## 翻译风格
- 目标：简体中文，**自然、口语化**，符合 2005 年日式 AVG 的表达习惯，不要翻译腔
- 保留角色语气特色：
  - 綾：活泼、元气、语气词多（だよ／だぁ／ねー／ほら），中文用「啦」「哦」「嘛」「诶」
  - 摩菜：内敛、寡言、礼貌（です／ます），中文短句、稍书面但克制
  - 英之：成年男性内心独白，略带自嘲，第一人称「我」
  - 沙織：温柔母亲
- 旁白：以「我」叙述的第一人称内心戏，保持文学性但要好读
- 颜文字/拟声词（くすくすくすっ、ふわーーーー）要译出感觉，如「嘻嘻嘻」「呼ーーーー」
- 「aby／あや」是綾的昵称，译作「小绫」或保留「阿绫」，全文统一
- 妹妹称呼「お兄さま／お兄ちゃん」→ 摩菜用「哥哥」，綾用「哥哥」（统一即可，不必强求区分）

## 绝对约束
1. **不要丢失或新增任何控制字符**（`\x00` `\x01` `\x02` `\x03` `\x04`）
2. 不要翻译资源名（cg91、aya_3320、vf10 之类）
3. 不要输出解释性文字，只输出纯 JSON
4. 译文长度尽量与原文接近（±30% 以内），避免超出对话框
5. 若原文含 `\u3000`（全角空格）缩进，译文同样以 `\u3000` 开头
