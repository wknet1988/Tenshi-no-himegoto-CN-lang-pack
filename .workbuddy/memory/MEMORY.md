## ★ 汉化方案（已重构为 cp932 直出，零运行时补丁）

### 1. 核心思路
译文以 **cp932 (Shift-JIS) 直出** 写入数据包，引擎原样用 932 解码即可正确显示。
关键前提：简化字必须先经 `tools/to_jp.py` 映射成 **cp932 可编码的日文/繁体字形**
（映射表 `.work/glyph_map.json`），否则 `cp932` 编码失败会被替换成 `?`/中点。

### 2. 构建流水线（顺序不可颠倒）
1. `python tools/lcse_tool.py extract tenshi .work/extract`  — 从原版解包日文底稿（明文，XOR 0x02 解密）
2. `python tools/to_jp.py --apply`  — 把 `.work/zh/*.json` 里的简化字映射成 cp932 字形（in-place 改写）
3. `python tools/build_zh.py`  — inject(译文→extract) + repack_all(→ .work/build/lcsebody + .lst)
4. 把 `.work/build/lcsebody` 与 `.work/build/lcsebody.lst` 复制到 `cn/`

### 3. 运行时（launch_cn.py）
- **零编码补丁**：数据是 cp932，引擎默认 932，无需改 CP_TEXT/charset/DBCS。
- launch_cn 仅把窗口标题 `LC-ScriptEngine ver1.0` 改成 `天使秘事`（TITLE_SITE=0x8EF40）。
- 字体名保持 ＭＳ 明朝/ゴシック 原样（译文已映射到日文汉字字形，该字体可显示）。
- 双击 `run_cn.bat` 启动（用工作目录内嵌入式 Python `python/python.exe`）。

### 4. 文件命名约定
- 游戏目录 `cn`、启动器 `launch_cn.py`、批处理 `run_cn.bat`，脚本内不得出现中文字符。

## 代码约定
- 目录：`.work/extract/`（明文解包）、`.work/zh/*.json`（译文）、`.work/build/`（数据包产物）
- **`.work/extract/` 内文件一律为明文**；repack 时才 XOR 0x02 加密
- 译文 JSON：key = `<文件名>#<字符串下标>`，value = 含完整控制符（\x01 \x02 \x03 \x04）的字符串
- 说话人字段（如 `绫\x01「…」`）**不翻译**，引擎靠它匹配立绘/字体
### ★ 字形映射 policy（用户拍板，勿再用形近兜底）
`.work/glyph_map.json`（单字 → cp932 可编码字形）。对 cp932 不可直接编码的字，**优先级**：
1. **繁体中文字形**（表 OpenCC s2t / zhconv）
2. **日文新/旧字体**（OpenCC t2jp）
3. 前两者都不可编码时，才用**意思相近的字**替换
→ **禁用「字形部件相似」兜底**：那会产出语义错误的替换（曾把「这」替成形近的「迄」）。
偏好能被严格 `shift_jis`（JIS X 0208 标准区）编码的字形，其次才是 cp932 厂商扩展区（保渲染安全）。
重建脚本：`.work/build_glyph_map.py`（繁体/日文字体，需外网装 zhconv+opencc，在隔离 venv 跑，
产物固化进 json；build 流水线仍零依赖）+ `.work/curate_glyph_fallback.py`（人工近义替换）。
coverage/检查用 `python tools/to_jp.py`（当前：1381 字 = 928 直接 + 453 映射，**unrecoverable 0**）。
注意：`.work/zh/*.json` 会被 to_jp 就地改写；**原始简体基准是 `.work/zh_backup/*.json`**。
**支持「一字 → 多个假名」**：`to_jp.py` 的 `usable()` 允许值为多字符（每个字符都须是合法 Shift-JIS
双字节）。这是处理拟声词/语气助词/人称代词的关键——她→彼女、砰→バタン、嘻→くす、嘟囔→ぶつぶつ。
**替换值必须从日文原作（tenshi 原文）取真实写法**，别凭感觉；本身可码且在严格 JIS 标准区的拟声/
语气字（唔/哇/哦/嘛）保留原样。
- 打包后结构校验：1135 条记录、unk 分布 1:156 / 3:979

## 环境限制（沙箱内）
- DirectInput 的 COM 创建返回 E_FAIL → 游戏约 30 秒后崩溃（0xC0000005），**原版同样如此**，
  属老游戏 + Win11 兼容问题，与汉化无关
- 沙箱无法向游戏窗口投递真实输入 / 看不到 GUI，显示效果需用户在真实桌面确认
- `ReadProcessMemory` / `WriteProcessMemory` 可用
